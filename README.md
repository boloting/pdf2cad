# PDF2CAD：矢量 PDF 图纸转 DXF

PDF2CAD 把矢量 PDF 图纸（由 CAD 导出或打印的 PDF）转成 DXF，并尽量把笔画还原成真正的 CAD 对象，而不是打散的线条：

| PDF 里的内容 | 转成的 DXF 对象 |
| --- | --- |
| 尺寸线 + 界线 + 箭头/斜线/圆点 + 数字 | `DIMENSION` 线性/对齐标注，数值与几何关联（`<>`） |
| 指向圆的引线 + `Φ12` / `R6` | `DIMENSION` 直径/半径标注 |
| 箭头 + 折线 + 文字 | `LEADER` + `TEXT` |
| 闭合的实心填充路径 | 实心 `HATCH` |
| 等距平行线（含交叉线、带孤岛） | 图案 `HATCH`，45° 线命名为 `ANSI31` / `ANSI37`，边界自动查找 |
| 重复出现的图形（平移、旋转 90°/180°/270°） | `BLOCK` 定义 + `INSERT` |
| 文本对象 | `TEXT`，保留字高、角度和图层，`Ø ± °` 转成 `%%c %%p %%d` |
| 四段贝塞尔曲线组成的圆、圆弧 | `CIRCLE` / `ARC`，多段路径写成带凸度的 `LWPOLYLINE` |
| 其他曲线 | `SPLINE` |
| PDF 图层（可选内容组） | 同名图层；没有图层时按颜色和线宽分层 |
| 虚线、点划线（含被打散成一段段短划的） | 合并成整条 `LINE`，按实际间距生成线型 |
| 轴线 + 轴号圆圈（含附加轴号 `1/2`） | 整条轴线放在 `PDF_轴线` 图层；轴号做成带属性的图块，双击可改编号 |
| 线宽、颜色 | 线宽和颜色（标准色用 ACI，其余用真彩色） |

程序还会比对标注数字和图上长度，自动推算绘图比例（例如 1:100），按真实尺寸输出模型。“适合纸张”缩放打印出来的非标准比例（例如 1:104.17）也能推算出来。

标注数字被“转曲”成笔画或轮廓时（CAD 用 SHX 字体打印 PDF 常见），程序会按字形自动识别数字，照样重建标注。其余转曲文字（房间名、门窗编号、说明、图签等）用文字识别（OCR）还原成可编辑的单行文字，放回原位置、原字高、原角度；把握不大的放在 `PDF_文字_待核对` 图层，方便在 CAD 里逐个核对。

## 运行

需要 Python 3.12+ 和 [uv](https://docs.astral.sh/uv/)。

```bash
uv sync
```

### 网页界面

```bash
uv run pdf2cad-web          # 默认 http://127.0.0.1:8765
PORT=9000 uv run pdf2cad-web
```

上传 PDF 后，可以在三种视图里查看结果：

- **识别着色**：按识别结果着色，标注蓝色、图块绿色、填充橙色、文字紫色。
- **DXF 预览**：转换后的 DXF。
- **原始 PDF**：原图，方便对比。

确认无误后下载 DXF。页面上的“用示例图纸试一试”会载入内置的示例图纸。

### 命令行

```bash
uv run pdf2cad 图纸.pdf                   # 输出 图纸.dxf，比例按标注自动识别
uv run pdf2cad 图纸.pdf -o 输出.dxf -s 100 # 手动指定 1:100
uv run pdf2cad 图纸.pdf --all-pages       # 每页一个 DXF
uv run pdf2cad 图纸.pdf --no-blocks --json # 关闭图块识别，输出 JSON 报告
uv run pdf2cad 图纸.pdf --no-ocr          # 不识别转曲文字（快很多）
uv run pdf2cad 图纸.pdf --ocr             # PDF 里有真文字也强制识别转曲文字
```

默认情况下，PDF 里几乎没有真文字、又有大量图形时才会启用文字识别。一张 A0 平面图识别大约需要 2 分钟。网页界面里对应“转曲文字识别”开关。

### Python

```python
from pdf2cad import Options, convert_file

result = convert_file("图纸.pdf", Options(page=0, scale=None))
result.doc.saveas("图纸.dxf")   # ezdxf 文档
print(result.report.recognized)
```

### 测试

```bash
uv run pytest
```

`examples/sample.pdf` 是示例图纸（安装板，1:2），`examples/sample.dxf` 是它的转换结果。重新生成示例：`uv run python -m pdf2cad.sample examples/sample.pdf`。

## 工作原理

1. **提取**（`extract.py`）：用 PyMuPDF 读取页面路径和逐字文字，统一成纸面毫米、y 轴向上的坐标。四段贝塞尔圆拟合回圆或圆弧，同一基线上的字符合并成字符串。
   - **轴线与轴号**（`axes.py`）：多边形画的圆拟合回圆。很多 CAD 打印 PDF 时把点划线拆成一段段独立的短划和点，程序把同一直线上的短划按“划长 + 节距”找出规律，合并成一整条线并生成对应线型；压在轴线上的墙线、界线、错位的另一条虚线不会被并进来，墙下缺失的几段也能跨过去。这一步放在识别标注之前，免得轴线的短划被当成界线。接着找连着引出线或被轴线穿过的圆圈作为轴号，圈内的字单独识别（字母不含 I、O、Z）；带斜线的附加轴号分成分子、分母两部分识别。轴号写成带属性的图块，和它相连的整条轴线放到 `PDF_轴线` 图层。
2. **标注**（`dims.py`）：先识别箭头（实心或空心三角、开口箭头、建筑斜线、圆点）。建筑斜线可以是线段，也可以是加粗后转成的细长填充块。两端都有箭头的直线是尺寸线；一整排连续标注只画了一根线时，按线上每个斜线位置切分。然后为每段匹配最近的平行数字文字，并找同样式、垂直、穿过端点的界线。指向圆周的箭头折线配上 `Φ` 或 `R` 文字，就是直径或半径标注；其余的箭头折线加文字是引线。
   - **转曲数字**（`stroketext.py`）：同一种字体里，同一个数字每次画出来都一样，所以尺寸线旁的字形可以按形状聚类。程序用每个标注的实测长度去试各种比例（含非标准比例），找出“同一种字形总对应同一个数字”的那个比例，同时得到字形到数字的对照表，再逐个读出标注数字。读数和实测长度对不上的标注不重建，保留为原图形。一排很短的连续标注，数字常常首尾相接、分不出哪几个字属于哪一段；这时按“长度×比例”算出每段应有的数值，在尺寸线旁读出的数字串里找到对应的几个字，长的尺寸先配。
3. **填充**（`hatch.py`）：填充路径转成实心 `HATCH`。同样式、等间距的平行线族转成图案 `HATCH`。成行错位排列的短线（“+”绿化符号、虚线铺装）按行距、短线长、行间错位拟合成带虚线的图案线，“+”的横竖两笔合成同一个填充，一整片区域只生成一个 `HATCH`，不再是几千个小图块。边界优先用图上已有的闭合轮廓（含孤岛）；如果这个轮廓把没有填充的地方也圈进来了，就改用逐行图案端点拼出的区域轮廓。“+”点阵在识别文字之前先收掉，压在点阵上的文字不会和“+”混在一起被读错。
4. **图块**（`blocks.py`）：把相互接触的小图形分组，在四个旋转方向上计算规范化签名，签名相同的组归为同一个图块。墙线、图框这类长线不参与分组，所以贴着墙的门窗也能单独成块。
5. **转曲文字**（`ocrtext.py`）：把剩下的小图形按每毫米 14 像素分块渲染，用 RapidOCR（ONNX 模型，离线运行）识别横排文字，竖高的框再转 90° 单独识别竖排文字。每个识别框对应回框内的字形，识别出的文字替换掉这些字形。相同形状的字形串投票统一读法，再按建筑图常用词纠正易混字（如“项/顶”“申/甲”“问/间”）。一行字中间有表格竖线时，按格拆开分别识别；检测不到的孤立数字（表格里单独的“0”）按字高找出来直接识别。竖排数字被横着读出的碎片（竖排“8400”里横读出的“00”“4”）会作废，交给竖排识别整串重读。识别出的数字再和尚未重建的尺寸线配对，数值和“图上长度×比例”相差不超过 10% 的重建为标注；挤在一起读成一串的数字（如“200,200”）会按尺寸拆开。
6. **写出**（`writer.py`）：用 ezdxf 写 R2018 DXF，生成标注样式、`PDF_TEXT` 文字样式（`simplex.shx` + 大字体 `gbcbig.shx`）、线型和图层。从 PDF 量出的字高、斜线大小、界线超出长度带有零点零几毫米的误差，相差 4% 以内的归为同一个值并取整（如 2.69 → 2.7）。标注样式按 AutoCAD 的习惯写：尺寸是纸面毫米，`DIMSCALE` 等于绘图比例（例如字高 2.7、斜线 1.5、全局比例 100），这样在 AutoCAD 里新建标注时，外观会和图上已有的标注一致。建筑斜线用 `DIMTSZ` 画。每种外观一个样式：最常见的叫 `PDF`，其余按“箭头类型 + 字高 + 箭头大小”命名（如 `PDF_斜线3.8_1`）。标注本身只在界线长度和原图不同、或隐藏了某条界线时才带替代。

## 限制

- 只支持矢量 PDF。扫描件或图片 PDF 里没有可用的几何。
- 转曲文字靠 OCR 识别，不保证全对：原图里互相压在一起的数字、贴着别的图形的单个字、特殊符号容易出错或漏掉。把握不大的结果在 `PDF_文字_待核对` 图层；识别不出的字形保留为原图形。
- 识别出的文字是单行文字（`TEXT`），多行说明按行拆开；字体统一为 `simplex.shx` + `gbcbig.shx`，宽度用宽度因子贴合原文字。
- 标注重建后，若实测值四舍五入后和原图数字一致，显示为测量值 `<>`；不一致（PDF 坐标有约 0.01 mm 误差，或原图本来就改过数字）则直接写原图上的数字。标注不会和几何绑定（没有关联标注）。角度标注、坐标标注和弧长标注暂不识别。
- 图块名由程序生成（`PDF_BLOCK_01`…），PDF 里没有原来的块名和属性。镜像的图块实例不会和原块合并。
- 椭圆写成 `SPLINE`。
- 一页里的多个视口按同一个比例输出；比例不同的局部视图需要在 CAD 里自行缩放。
- DXF 里的文字样式使用 `simplex.shx` + `gbcbig.shx`，AutoCAD、中望 CAD、浩辰 CAD 一般自带，打开不会乱码；如果电脑上没有 `gbcbig.shx`，CAD 会提示替换字体，选任意中文大字体（如 `hztxt.shx`）即可。

## 目录

```
src/pdf2cad/
  extract.py   PDF 路径与文字提取、曲线拟合
  axes.py      打散点划线合并、轴线与轴号
  dims.py      箭头、线性/对齐/半径/直径标注、引线
  stroketext.py 转曲数字的字形聚类与自学习识别
  ocrtext.py   转曲文字的 OCR 识别、投票与纠错
  hatch.py     实心与图案填充、边界查找
  blocks.py    重复图形 -> 图块
  writer.py    DXF 输出（ezdxf）
  convert.py   流水线、比例推算、报告
  preview.py   PDF 与 DXF 的 SVG 预览
  web.py       FastAPI 网页服务
  cli.py       命令行
  sample.py    示例图纸生成器
  static/      网页前端
tests/         测试与合成测试图
```
